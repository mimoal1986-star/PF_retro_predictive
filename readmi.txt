Основные функции
1. Загрузка данных (app.py)

    Принимает 4 обязательных Excel-файла:

        Массив.xlsx — данные с портала (проверки)

        Автокодификация.xlsx — справочник проектов

        Гугл таблица.xlsx — проекты из Сервизории

        ЗОД+АСС.xlsx — иерархия руководителей

2. Очистка данных (DataCleaner)

Для Гугл таблицы (7 шагов):

    Удаление дубликатов по коду проекта и датам

    Чистка пробелов в кодах проектов

    Заполнение пустых кодов

    Форматирование значений (Пилот/Семпл/Мультикод)

    Заполнение пустых дат

    Корректировка дат по бизнес-правилам

    Добавление признака "Полевой" (отложено)

Для Массива:

    Замена нулевых дат на "1900-01-01" (суррогатная дата)

    Замена значений "Н/Д" на пустые строки

    Сохранение информации о строках с Н/Д для отчетности

3. Обогащение данных

    Сопоставление данных Массива с Проектами Сервизория

    Заполнение пустых "Кодов анкеты" в Массиве по правилам:

        Имя клиента (Массив) → Проекты в https://ru.checker-soft.com (Проекты)

        Название проекта (Массив) → Название волны на Чекере (Проекты)

4. Классификация проектов

    Определение "полевых" проектов: проверка кодов в Автокодификации с направлением .01 или .02

    Добавление флага "Полевой" в Гугл таблицу и Массив

    Разделение Массива на:

        Полевые проекты (флаг = 1)

        Неполевые проекты (флаг = 0)

5. Экспорт результатов

Создание Excel-файлов с вкладками:

    Очищенный массив

    Очищенные проекты (оригинал + очищенный)

    Разделенный массив (полевые/неполевые проекты + статистика)
